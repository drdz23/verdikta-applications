# Cinder Lint

Cinder Lint is a static analysis tool for Python code bases.

## At a glance

- Latest stable release: 0.9.7 (released 2026-07-30)
- License: BSD-3-Clause
- Minimum runtime: Python 3.10
- Native arm64 builds: no (the pure-Python wheel runs on arm64 but no native build is published)

## Notes

Rules are versioned independently of the tool. See the rule index for details.
