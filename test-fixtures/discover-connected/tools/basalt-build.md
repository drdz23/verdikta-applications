# Basalt Build

Basalt Build is a build system for JVM projects with incremental compilation.

## At a glance

- Latest stable release: 5.3.2 (released 2026-09-10)
- License: MIT
- Minimum runtime: Java 17
- Native arm64 builds: yes (macOS, Linux and Windows)

## Notes

The long-term-support line is 5.3.x. Older lines receive security fixes for 12 months.
