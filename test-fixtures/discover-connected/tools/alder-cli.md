# Alder CLI

Alder CLI is a command-line task runner for JavaScript monorepos.

## At a glance

- Latest stable release: 2.14.0 (released 2026-08-21)
- License: Apache-2.0
- Minimum runtime: Node.js 20
- Native arm64 builds: yes (macOS and Linux)

## Notes

Prerelease builds are published to the `next` channel and carry no stability guarantee.
