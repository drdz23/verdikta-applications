# Jetty Watch

Jetty Watch is a file watcher that restarts services on change.

## At a glance

- Latest release: 3.0.0-rc.2 (prerelease, released 2026-09-20). Latest stable release: 2.9.4 (released 2026-04-14)
- License: Apache-2.0
- Minimum runtime: Go 1.21
- Native arm64 builds: yes

## Notes

The 3.0 release candidates change the configuration format. Stay on 2.9.x until 3.0 is marked stable.
