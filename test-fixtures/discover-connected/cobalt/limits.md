# Cobalt Ledger Store 2.7: Limits

| Limit | Default |
|---|---|
| Buckets per account | 100 |
| Maximum object size (multipart) | 5 TB |
| Maximum object key length | 1,024 bytes |
| Keys returned per ListObjects page | 1,000 |
| Parts per multipart upload | 10,000 |
| Request quota per bucket | 5,500 requests per second |

The bucket limit can be raised by contacting your account manager. The other limits are fixed.
