# Cobalt Ledger Store 2.7: Frequently asked questions

**Does Cobalt support object lock?**
Yes. Object lock is available from release 2.5 with two retention modes: governance, where privileged users can shorten the retention period, and compliance, where nobody can shorten retention until it expires.

**Is there a free tier?**
No. Cobalt Ledger Store is billed from the first byte stored. A 30-day evaluation credit is available through your account manager.

**Does Cobalt support HTTP/2?**
Yes. The data plane has supported HTTP/2 since release 2.6. The control plane uses HTTP/1.1.

**Which languages have official SDKs?**
Official SDKs exist for Go, Java, Python and TypeScript. Community SDKs for other languages are listed in the developer portal.

**Where do I report a security issue?**
Email the security team at the address shown on the developer portal's security page. Please do not open a public issue.
