# Gorse Format

Gorse Format is an opinionated source formatter for Rust.

## At a glance

- Latest stable release: 7.0.1 (released 2026-09-25)
- License: ISC
- Minimum runtime: Rust 1.78
- Native arm64 builds: yes

## Notes

Gorse Format reads its configuration from `gorse.toml` in the project root.
